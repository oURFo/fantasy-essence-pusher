# 共用角色 v3 生成與裝配紀錄

使用內建 imagegen，透明 PNG。先繪製完整共用素體三視圖，再以素體作為編輯參考換裝；不再把獨立生成的手腳拉伸拼接。所有男女／造型存檔共用同一頭部。

站姿：base、arcade、denim、rose，各三視圖，正面／右側／背面。hair 為三髮型乘三視圖；accessories 為四配飾乘三視圖。表情沿用 rig-v2/expressions.png。

walk-*：四欄乘三列，正面／右側／背面，完整服裝與肢體。完整頸部以下以頸點與腳底等比例註冊，不分段拉伸；頭部固定使用 master。現有服裝皆採對稱設計，正背面後半步鏡射身體以交替領先腳；非對稱新服裝需另備正確相反步幅，不可直接鏡射圖樣。最初六欄走路稿因側面姿勢重複而未採用。

固定接點、帽子遮擋、髮色與表情由 src/avatar-rig.ts、avatar-rendering.ts 管理。開發三視圖檢查頁：tools/avatar-review.html。
